# Derivation audit for `RQ2-COMMON-COORDINATE-TARGET-001`

Status: **mathematical design audited; no implementation or run.**

## Audit question

Can the calculation used by projected GD be changed to the residual of the
registered bounded-coordinate recurrence without also changing state freedom
or the update operator?

Yes, conditionally: restrict the full edge residual to the tied manifold and
pull its partial derivatives back to the scalar state. Do not average the map
output before forming the residual.

## Tied geometry

For `z=Bx`, `W_(i->c)=1/d_i`, `C=B'W`, and `P=BC`,

```math
B^{\mathsf T}WB=I,
\qquad C B=I.
```

For any edge vector `y`, `Py` replaces the values on all edges incident to a
bit by their weighted mean. Because `P^2=P` and `P'W=WP`, the range of `B` and
the range of `I-P` are orthogonal under the `W` inner product.

## Full residual versus mean target

Write

```math
r(x)=Bx-\Phi(Bx),
\qquad
\psi(x)=C\Phi(Bx).
```

Insert `P+(I-P)=I` and use `PBx=Bx`:

```math
r(x)=B[x-\psi(x)]-(I-P)\Phi(Bx).
```

The two terms are `W`-orthogonal, and `B` is a `W`-isometry. Therefore

```math
\frac{1}{2n}\|r(x)\|_W^2
=\frac{1}{2n}\|x-\psi(x)\|_2^2
 +\frac{1}{2n}\|(I-P)\Phi(Bx)\|_W^2.
```

The second term is the recipient-specific disagreement generated by the
registered recurrence from a tied input. A mean-target objective drops it.
That would be a
different experiment and would make a later equality-release rung change the
objective as well as state freedom.

## Normalization audit

Without `1/n`, the weighted residual sum is `O(n)` and each partial derivative
is `O(1)`. The inherited projected-GD preconditioner has entries `O(1/n)`, so
the resulting direction would be `O(n)` and would usually measure arbitrary
global scale and box saturation along with the changed calculation.

With

```math
H_{\mathrm{tie}}(x)=\frac{1}{2n}\|r(x)\|_W^2,
```

the objective is a mean squared residual per bit, partial derivatives are
`O(1/n)`, and the inherited preconditioned direction remains `O(1)`. The
normalization is structural and must be frozen before outcomes. It is not a
tunable coefficient.

## Pullback partial derivatives

For a perturbation `dx`,

```math
dr=(I-J_\Phi(Bx))B\,dx.
```

Hence

```math
dH
=\frac{1}{n}r^{\mathsf T}W(I-J_\Phi)B\,dx,
```

and

```math
\nabla H
=\frac{1}{n}B^{\mathsf T}(I-J_\Phi)^{\mathsf T}Wr.
```

This is a Jacobian-transpose pullback into the one-scalar-per-bit state. It is
not direct application of `Phi`.

## Local derivative chain

Let `D^reg` denote the ordinary derivative on a smooth branch and the
prospectively registered value at a kink. For `j` in `N(c)\{i}`, the selection
is

```math
D^{\mathrm{reg}}_{z_{j\to c}}U_{c\to i}
=\begin{cases}
\displaystyle
\frac{2}{1-p_{c\to i}^2}
 \prod_{k\in N(c)\setminus\{i,j\}}z_{k\to c},
 & |p_{c\to i}|<\eta,\\[6pt]
0, & |p_{c\to i}|>\eta,\\
0\ \text{(registered kink selection)}, & |p_{c\to i}|=\eta.
\end{cases}
```

For the output transformation,

```math
D^{\mathrm{reg}}_{q^+_e}\Phi_e
=\begin{cases}
\frac12(1-\Phi_e^2), & |q^+_e|<20,\\
0, & |q^+_e|>20,\\
0\ \text{(registered kink selection)}, & |q^+_e|=20.
\end{cases}
```

Recipient exclusion supplies the sparse mathematical routing from each
`U_(d->i)` to every `q^+_(i->c)` with `d!=c`. The primal implementation must
nevertheless preserve native floating-point order: accumulate all incident
`U` values into `Lambda_i` and then subtract `U_(c->i)`. The reverse chain must
mirror that registered arithmetic and be checked by an independent dot-product
identity

```math
v^{\mathsf T}(J_\Phi w)=(J_\Phi^{\mathsf T}v)^{\mathsf T}w.
```

## Clamp convention and reachable domain

The primal recurrence is native-exact on the bounded BP-reachable subdomain. The
projected-GD state can reach `+/-1`, so the existing product clamp is a frozen
extension outside that subdomain. No new per-edge clip is permitted.

For the constructed derivative, every clip uses a generalized-derivative
selection of one in its strict interior and zero outside or exactly at the
boundary. The zero at a kink is an algorithmic selection, not an ordinary
partial derivative. Symmetric finite differences must be separated from every
map kink and from `|x_i|=1`. At a map-clamp kink, the zero selection is checked
from the clipped outward side while the distinct inward slope is recorded. At
the state-box boundary, use an inward constrained directional check and test
projection separately. Counts of product clamps, LLR clamps, and
`|x_i|>eta` visits are required diagnostics.

## Audit verdict

- **Pass:** the full registered-recurrence residual restricted to tied state
  changes only the
  objective calculation and its partial derivatives.
- **Rejected alternative:** `0.5/n ||x-C Phi(Bx)||^2` discards the
  recipient-specific disagreement term.
- **Rejected alternative:** freeing edge values also changes state freedom.
- **Rejected alternative:** assigning `Phi(Bx)` directly changes the update
  operator.
- **Rejected alternative:** reconstructing LLRs with `2*atanh(z)` changes the
  validated clipped recurrence.

The derivation is eligible for implementation only after the remaining
protocol blockers in `preimplementation_audit.md` are closed.
