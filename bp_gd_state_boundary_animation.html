Math and conventions used by the animation

Belief propagation using the sum-product algorithm

Qi→a(t) = Li + Σb∈N(i)\aUb→i(t−1)

Each check here joins two bits and requires them to agree; therefore Ua→i is the other incoming Q.

Λi(t) = Li + Σa∈N(i)Ua→i(t)

This page places the iteration boundary after the check calculation, so the four U values feed the next variable calculation.

Native projected gradient descent

J(x) = −(wch/(2n))Σiℓixi + (wpar/n)Σa(1−∏j∈axj)² + (wbin/n)Σi(1−xi²)²

ga,i = −(2wpar/n)ra∏j∈a,j≠ixj,   ra = 1−∏j∈axj

Di = (2wpar deg(i)+8wbin)/n, giving D = (1.866667, 3.2, 1.866667).

x+ = clip(x − ηD−1∇J, −1, 1), with wch=1, wpar=2, wbin=0.2 and accepted η=0.2.

The displayed check terms in each partial derivative of the objective function are recomputed from the frozen x and combined by coordinate.
