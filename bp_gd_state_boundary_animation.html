Math and conventions used by the animation

Belief propagation using the sum-product algorithm

Q_{i\to a}^{(t)} = L_i + \sum_{b\in N(i)\setminus a} U_{b\to i}^{(t-1)}

Each check here joins two bits and requires them to agree; therefore U_{a\to i} is the other incoming Q.

\Lambda_i^{(t)} = L_i + \sum_{a\in N(i)} U_{a\to i}^{(t)}

This page places the iteration boundary after the check calculation, so the four U values feed the next variable calculation.

Native projected gradient descent

J(\mathbf{x}) = -\frac{w_{\mathrm{ch}}}{2n}\sum_i \ell_i x_i + \frac{w_{\mathrm{par}}}{n}\sum_a\Bigl(1-\prod_{j\in a}x_j\Bigr)^2 + \frac{w_{\mathrm{bin}}}{n}\sum_i\bigl(1-x_i^2\bigr)^2
g_{a,i} = -\frac{2w_{\mathrm{par}}}{n}\,r_a\prod_{j\in a,\,j\neq i}x_j, \qquad r_a = 1-\prod_{j\in a}x_j
D_i = \frac{2w_{\mathrm{par}}\deg(i)+8w_{\mathrm{bin}}}{n}, \qquad \mathbf{D} = (1.866667,\ 3.2,\ 1.866667)
\mathbf{x}^{+} = \operatorname{clip}\bigl(\mathbf{x}-\eta\,\mathbf{D}^{-1}\nabla J,\ -1,\ 1\bigr)

with w_{\mathrm{ch}}=1, w_{\mathrm{par}}=2, w_{\mathrm{bin}}=0.2 and accepted \eta=0.2.

The displayed check terms in each partial derivative of the objective function are recomputed from the frozen \mathbf{x} and combined by coordinate.
